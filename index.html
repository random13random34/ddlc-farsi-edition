What is the DDLC Persian Mod?

The DDLC Persian Mod is a comprehensive, community-driven Persian (Farsi) language patch for the beloved visual novel Doki Doki Literature Club by Team Salvato. This mod replaces every line of in-game dialogue, all menu text, poem evaluations, and even the special ending sequences with meticulously translated Persian text — preserving the original tone, humor, and emotional weight of the story.

Created independently by K_F_, this project is a labor of love aimed at making DDLC accessible to millions of Persian-speaking visual novel fans around the world. Whether you're a seasoned DDLC player experiencing the game anew, or a first-time player exploring the Literature Club, this mod ensures you don't miss a single nuance.

How to Install

Get up and running in under two minutes.

  1. 1

    Download the Mod

    Click the download button or visit the GitHub repository to download the latest release ZIP file.

  2. 2

    Extract the Files

    Unzip the downloaded file to any convenient location on your computer using your preferred archive tool.

  3. 3

    Copy to DDLC Directory

    Move the extracted mod files into your Doki Doki Literature Club game folder (the one containing game/ directory). Replace any existing files if prompted.

  4. 4

    Launch and Play!

    Start DDLC as usual — the game will now run entirely in Persian. Enjoy the Literature Club in a whole new language!

Frequently Asked Questions

What is the DDLC Persian Mod?
The DDLC Persian Mod is a complete Persian (Farsi) language translation for the visual novel game Doki Doki Literature Club, created by K_F_. It translates all dialogue, menus, and interface text into Persian, allowing you to experience the full game in your native language without losing any of the original emotional impact or story nuance.
Is the DDLC Persian Mod free to use?
Yes, absolutely! The DDLC Persian Mod is 100% free and open-source. There are no hidden costs, paywalls, or premium tiers. You can download the full translation from GitHub and use it without any restrictions. The project is a labor of love by K_F_ for the DDLC community.
How do I install the mod?
Installation is simple: download the mod files from the GitHub repository, extract the ZIP, and copy the contents into your Doki Doki Literature Club game directory. Detailed step-by-step instructions are available in the Installation Guide section above and in the repository's README file.
Does this mod work with DDLC Plus?
The DDLC Persian Mod is designed for the original free version of Doki Doki Literature Club (the Ren'Py desktop version). Compatibility with DDLC Plus (the console/mobile release) may vary. Check the GitHub repository for the latest compatibility updates and any specific versions the mod supports.
Can I contribute to the translation?
Yes! The project is fully open-source on GitHub. You can report translation issues, suggest better phrasing, or submit pull requests with improvements. K_F_ welcomes community contributions to help make the Persian translation even more accurate and natural. Visit the repository to get started.
Who created this mod?
The DDLC Persian Mod was created by K_F_ (also known as kf), a dedicated DDLC fan and Persian language enthusiast. You can find K_F_ on GitHub at github.com/kiyanfnaflover-ui.
